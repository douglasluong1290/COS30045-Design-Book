0. PREREQUISITES
----------------------------------------------------------------
Install runtime dependencies:
    npm install d3
    npm install xlsx           (build-time only, for data conversion)
    npm install topojson-client (only if Ch 2 uses a choropleth)

Convert thanh_analysis/datasets/transformed_datasets.xlsx into JSON
files under public/data/. Use a one-shot Node script (not committed to
the runtime bundle):

    scripts/build-data.mjs
      - read each sheet via xlsx
      - replace "n.p." strings with null
      - pre-aggregate to the grain each chart needs
      - write JSON to public/data/

Outputs (one file per chart concern):

    public/data/national_trend.json
        [{ year, cases, bed_days, hospitalisations, phase }]
        phase ∈ "before" | "during" | "after"  (DAX-equivalent rule:
        year ≤ 2019 → before, 2020 → during, ≥ 2021 → after)

    public/data/state_trend.json
        [{ state, year, cases, bed_days }]

    public/data/age_sex.json
        [{ age_band, sex, cases, bed_days }]   (aggregated over years)

    public/data/road_user.json
        [{ road_user, cases, bed_days }]
        ALREADY FILTERED: rows where road_user === "Not applicable"
        are dropped at build time.

    public/data/counterparty.json
        [{ state, counterparty, cases, share }]

    public/data/convergence_matrix.json
        [{ state, road_user, cases, bed_days, bed_days_per_case }]

    public/data/population.json
        [{ state, year, population }]   (multi-year, from the new
        transformed dataset — supports proper per-capita normalisation)

    public/data/states.topo.json       (only if Ch 2 = choropleth)

Each chart module exports a single init() function that:
  1. fetches its data via loaders.js
  2. mounts an SVG inside its placeholder-canvas
  3. attaches step / slicer listeners
  4. returns a teardown handle (for HMR)

In main.js, after initScrollytelling() runs, import and call each init:

    import { initCh1 } from './charts/ch1-trend.js'
    import { initCh3 } from './charts/ch3-demographics.js'

3. CHAPTER 1 — Annotated National Trend
----------------------------------------------------------------
Module:  src/charts/ch1-trend.js
Mount:   #chart-1-trend > .placeholder-canvas
Data:    public/data/national_trend.json

Layout
  margin = { top: 30, right: 40, bottom: 40, left: 60 }
  responsive via SVG viewBox + preserveAspectRatio = "xMidYMid meet"

Scales
  x = d3.scaleLinear().domain([2011, 2021])
  y = d3.scaleLinear().domain([15000, 21000])   // truncated, label clearly

Layers (z-order bottom → top)
  1. Phase background rects:
       before  : x(2011) → x(2019.5), neutral fill
       during  : x(2019.5) → x(2020.5), amber rgba(245,158,11,0.12)
       after   : x(2020.5) → x(2021),   recovery rgba(170,59,255,0.08)
  2. Y gridlines (dotted, var(--border))
  3. Single line path:
       d3.line().x(d => x(d.year)).y(d => y(d.cases))
                .curve(d3.curveMonotoneX)
     stroke = var(--accent), stroke-width = 2.5
  4. Point circles per year: r = 4, fill var(--accent)
  5. Phase labels (text), 3 callout annotations, axes

Step behaviour
  Initial: every element opacity 0.
  step 1 → reveal line+points for 2011-2019; show "+19%" callout near 2019.
  step 2 → extend line+points through 2020; fade in amber band;
           drop vertical guide at 2020; show "-5%" callout.
  step 3 → extend through 2021; fade in recovery band;
           show "record high" callout at 2021.

Transitions
  d3.transition().duration(600).ease(d3.easeCubicInOut)
  Line extension: animate stroke-dasharray (getTotalLength) to "reveal".
  Bands / callouts: opacity fades.

Tooltip
  Voronoi-bound hover (d3.Delaunay.from over points) showing year + cases.

5. CHAPTER 3 — Age × Sex Clustered Bar + Sex Slicer
----------------------------------------------------------------
Module:  src/charts/ch3-demographics.js
Mount:   #chart-3-demographics > .placeholder-canvas
Data:    public/data/age_sex.json

Layout
  Full-width chart (chapter is .chapter--fullpage).
  margin = { top: 50, right: 80, bottom: 50, left: 80 }

Scales
  ageBands = ['0-7','8-16','17-25','26-39','40-64','65-74','75+']
  xAge      = d3.scaleBand().domain(ageBands).padding(0.2)
  xMeasure  = d3.scaleBand().domain(['cases','bed_days']).padding(0.1)
                            .range([0, xAge.bandwidth()])
  yCases    = d3.scaleLinear().domain([0, d3.max(d => d.cases)])
  yBeds     = d3.scaleLinear().domain([0, d3.max(d => d.bed_days)])
                          // right-side axis

Bars
  Two rect per age band — cases (fill var(--accent)) + bed days
  (muted neutral). Y uses yCases for cases bars, yBeds for bed-days
  bars.

Slicer wire-up (this is the primary interaction)
  const buttons = container.querySelectorAll('.slicer-mock button')
  let active = 'all'
  buttons.forEach(b => b.addEventListener('click', () => {
    buttons.forEach(x => x.classList.remove('is-active'))
    b.classList.add('is-active')
    active = b.dataset.value
    render()
  }))

  Filtering inside render():
    all    → group by age_band, sum cases + bed_days
    female → filter sex==="Female" before grouping
    male   → filter sex==="Male"   before grouping

Transitions
  Bars morph: d3.transition().duration(450)
              .attr('y', d => yCases(d.cases))
              .attr('height', d => yCases(0) - yCases(d.cases))

Annotations
  When active === 'female', show a pinned text label top-right:
      "≈ 53% of all hospitalisations"
  Use opacity transition; remove on slicer change.

n.p. handling
  null aggregate → render rect with fill="url(#hatch-pattern)" and
  tooltip text "value not published (small count)".

Tooltip
  On bar mouseenter: age band, sex (= active), cases, bed_days,
  bed_days / cases (severity).

8. SHARED MODULES
----------------------------------------------------------------
src/charts/theme.js
  Export colour tokens read from CSS at runtime so dark mode just works:

    const css = getComputedStyle(document.documentElement)
    export const colors = {
      accent : css.getPropertyValue('--accent').trim(),
      text   : css.getPropertyValue('--text').trim(),
      textH  : css.getPropertyValue('--text-h').trim(),
      border : css.getPropertyValue('--border').trim(),
      muted  : css.getPropertyValue('--social-bg').trim(),
    }
    export const fmt = {
      int    : d3.format(',d'),
      pct    : d3.format('.0%'),
      delta  : d3.format('+.0%'),
      days   : d => `${d.toFixed(1)} d`,
    }
  Re-read on matchMedia('(prefers-color-scheme: dark)').change.

src/data/loaders.js
  Cached fetch:
    const cache = new Map()
    export async function loadJSON(path) {
      if (cache.has(path)) return cache.get(path)
      const r = await fetch(path).then(x => x.json())
      cache.set(path, r); return r
    }

9. RESPONSIVENESS
----------------------------------------------------------------
- Every SVG declares viewBox and preserveAspectRatio = "xMidYMid meet".
- On window 'resize' (debounced 150 ms), recompute the bandwidth scales
  only; the viewBox handles the rest.
- Below 1024 px the chart-sticky becomes top-sticky and is given 55vh
  height by the existing CSS — make sure no chart renders below 320px
  height at that size.
